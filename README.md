# TSE_LOB | دریافت و تحلیل داده‌های تابلو و دفتر سفارشات بورس تهران

ابزار دسکتاپ‌محور و محلی برای دریافت داده‌های بازار سرمایه ایران از API عمومی TSETMC، نگهداری داده‌ها در پایگاه داده SQLite و تهیه خروجی‌های قابل استفاده در تحلیل‌های مالی و پژوهش‌های بازار.

> وضعیت پروژه: نسخه اولیه/آزمایشی. پیش از استفاده عملیاتی، خروجی‌ها را با منبع داده تطبیق دهید و محدودیت‌های پوشش تاریخی را بررسی کنید.

</div>

## قابلیت‌ها

- جست‌وجو و شناسایی نماد و ابزار معاملاتی.
- دریافت اطلاعات روزانه نماد و تاریخچه دفتر سفارشات (Order Book)، در محدوده‌ای که منبع داده ارائه می‌کند.
- انتخاب بازه زمانی و بازه ساعت معاملاتی.
- دریافت گروهی چند نماد و مشاهده وضعیت پیشرفت عملیات.
- ذخیره‌سازی محلی داده‌ها و فراداده‌ها در SQLite برای استفاده مجدد و کاهش دریافت تکراری.
- تهیه گزارش و خروجی داده در قالب‌های پشتیبانی‌شده توسط نسخه برنامه.
- تنظیم تعداد درخواست‌های هم‌زمان، تأخیر بین درخواست‌ها و تنظیمات اتصال.
- ارائه رابط وب محلی؛ برنامه به‌صورت پیش‌فرض روی `127.0.0.1` اجرا می‌شود.

## پیش‌نیازها

- Windows برای اجرای فایل راه‌انداز BAT.
- Python نسخه 3.10 یا بالاتر.
- اتصال اینترنت برای دریافت داده از سرویس TSETMC و نصب اولیه کتابخانه‌ها.
- فضای دیسک متناسب با بازه زمانی و تعداد نمادهای انتخاب‌شده.

کتابخانه‌های اصلی Python:

- Flask
- Requests
- jdatetime
- PyArrow (برای قابلیت‌های Parquet در صورت فعال بودن آن در نسخه برنامه)

## راه‌اندازی در ویندوز

1. فایل‌های برنامه را در یک پوشه استخراج کنید.
2. مطمئن شوید Python 3.10 یا بالاتر نصب است.
3. فایل BAT همراه نسخه انتشار را اجرا کنید.
4. در اولین اجرا، محیط مجازی و وابستگی‌های لازم ایجاد/نصب می‌شوند؛ این مرحله به اینترنت نیاز دارد.
5. پس از راه‌اندازی، نشانی محلی برنامه در پنجره کنسول نمایش داده می‌شود و مرورگر می‌تواند به‌صورت خودکار باز شود.

برای توقف برنامه، پنجره کنسول را فعال کرده و `Ctrl+C` را بزنید.

## اجرای مستقیم و آزمون

در محیطی که وابستگی‌ها نصب شده‌اند، فرمان‌های زیر قابل استفاده‌اند:

```powershell
python TSE_LOB.py --version
python TSE_LOB.py --self-test
python TSE_LOB.py --live-check فولاد
```

`--self-test` آزمون‌های داخلی را اجرا می‌کند. `--live-check` به اینترنت و دسترسی به API واقعی نیاز دارد. نام فایل Python و نام BAT باید با فایل‌های موجود در بسته انتشار یکسان باشد.

## داده‌ها و خروجی‌ها

برنامه داده‌های محلی، کش و فایل‌های خروجی را در مسیر داده‌ای که هنگام اجرا تعیین شده است نگهداری می‌کند. مسیر پیش‌فرض در نسخه کد فعلی، پوشه `tse_orderbook_data` در کنار فایل برنامه است؛ با آرگومان `--data-dir` می‌توان مسیر دیگری تعیین کرد.

پیش از حذف پوشه داده، از SQLite و فایل‌های خروجی نسخه پشتیبان تهیه کنید. پاک‌سازی کش می‌تواند باعث دریافت مجدد داده از سرویس شود.

## ملاحظات کیفیت داده

- خروجی برنامه بازتاب پاسخ API در زمان دریافت است و تضمین‌کننده کامل‌بودن تاریخچه در منبع نیست.
- روزهای فاقد داده، روزهای بدون معامله و خطاهای دریافت را یکسان فرض نکنید.
- تقویم معاملاتی و پوشش تاریخی را با گزارش برنامه و داده مرجع بررسی کنید.
- واحد قیمت و حجم را هنگام تحلیل کنترل کنید؛ فراداده فایل خروجی را نیز نگه دارید.
- برای پژوهش‌های حساس یا تصمیم‌گیری مالی، نتایج را با منبع رسمی و مستقل اعتبارسنجی کنید.

## امنیت و حریم خصوصی

- برنامه به‌صورت پیش‌فرض سرویس وب را فقط روی رابط loopback (`127.0.0.1`) اجرا می‌کند؛ آن را بدون بررسی امنیتی روی `0.0.0.0` یا شبکه عمومی منتشر نکنید.
- API base و پراکسی را فقط به نشانی‌های مورد اعتماد تنظیم کنید.
- محیط مجازی Python وابستگی‌ها را از نصب سراسری Python جدا می‌کند؛ این موضوع به‌تنهایی Sandbox امنیتی یا محافظت در برابر کد مخرب نیست.
- فایل‌های کش و خروجی ممکن است حاوی داده‌های موردنیاز تحلیل شما باشند؛ دسترسی پوشه را محدود و از آن پشتیبان تهیه کنید.
- این پروژه رمز عبور یا اطلاعات ورود کارگزاری را مطالبه نمی‌کند. چنین اطلاعاتی را در Issues یا Discussions منتشر نکنید.

## محدودیت‌ها

دسترسی، ساختار و پوشش داده تابع API و تغییرات احتمالی سرویس TSETMC است. تغییر API ممکن است دریافت برخی داده‌ها را مختل کند. تعداد درخواست‌های هم‌زمان بالا نیز ممکن است باعث محدودیت نرخ یا خطای سرویس شود؛ مقدار مناسب را تدریجی تنظیم کنید.
